## 这是什么

**织章** 是一个跑在用户本机的 AI 长篇小说创作工作台。用户给一份世界框架，它用六个 Agent 分工把整本小说写完，每一章都过四层一致性闸门；不一致的地方会被拦下来，在网页里一条条呈现给用户。

> 单次 LLM 调用做不了长篇——上下文窗口有限、没有持久状态、不会主动自检。
> 织章的解法是：**外部状态 + 多个专职 Agent + 确定性校验**。

---

## 核心能力

### 六个 Agent 分工

| Agent | 干什么 |
|-------|--------|
| **写手** | 按「章节合同」出初稿 |
| **抽取** | 把正文里的事实结构化，落进台账 |
| **审校** | 抓声口漂移、视角越界、术语误用、年代错误 |
| **裁决** | 对每条一致性问题给处置意见 |
| **编辑** | 按裁决修订正文 |
| **台账** | 验收后把角色状态、时间线、伏笔、局写回权威状态库 |

### 四层一致性闸门

| 层 | 类型 | 检查内容 |
|----|------|---------|
| **硬规则** | 确定性 | 死人不能出场 · 时间不能倒流 · 同场景不能两地 · 合同禁止项 |
| **关系图谱** | 确定性 | 关系对称性 · 地点层级 · 时间线单调 |
| **合同兑现** | 结构化 | Scheme 证据齐不齐 · 必须推进点 · 节奏 · 篇幅 |
| **LLM 语义审校** | LLM | 声口漂移 · 动机突变 · 视角越界 · 行业术语误用 · 年代错误 |

### 一键分镜（可选）

写完一章，点「分镜」tab：

- **5–15 张手绘漫画风分镜草图**
- **角色跨镜头一致**（用角色卡的 `appearance_prompt`）
- **场景视觉一致**（用地点卡的 `visual_prompt`）
- **图片模型不可用？** 输出完整 prompt，可复制到别的工具生图

### 本机运行，数据不出户

- 只监听 `127.0.0.1`
- 数据落本机数据目录，不上传云端
- 不采集 API Key
- 关页约 2.5 秒后服务自动退出
